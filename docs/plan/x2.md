# Load-Aware Reflected Routing for MoE

## 1. Setup

Let (E\ge 2) be the number of experts, and let (\mathcal X) be the token representation space. A token is a random variable (X\sim \mathcal D), where (\mathcal D) is the data distribution seen by the router.

For each expert (e\in{1,\dots,E}), let

* (f_e:\mathcal X\to\mathbb R^d) be the expert map,
* (a_e:\mathcal X\to\mathbb R) be the token-affinity score,
* (\mu_e>0) be the expert capacity weight,
* (c_e\ge 0) be a static offset,
* (\alpha>0), (\beta>0), and (\gamma\in\mathbb R) be routing hyperparameters.

Define the total capacity
[
\Lambda := \sum_{e=1}^E \mu_e.
]

The paper’s central state variable is the **load-pressure vector**
[
q(t)=(q_1(t),\dots,q_E(t))\in \mathbb R_+^E,
]
where (q_e(t)) measures the current pressure on expert (e).

---

## 2. Routing map

For (x\in\mathcal X) and (q\in\mathbb R_+^E), define the score
[
s_e(x,q)
:= a_e(x) + \gamma \log \mu_e - \frac{\alpha,(q_e+c_e)}{\mu_e^\beta},
]
the unnormalized weight
[
w_e(x,q):=\exp!\big(s_e(x,q)\big),
]
and the normalized routing probability
[
p_e(x,q):=\frac{w_e(x,q)}{\sum_{j=1}^E w_j(x,q)}.
]

Thus (\sum_{e=1}^E p_e(x,q)=1), and every expert receives a strictly positive soft routing mass.

The MoE layer output is
[
\mathrm{MoE}(x,q)=\sum_{e=1}^E p_e(x,q),f_e(x).
]

For the population router, define
[
\bar p_e(q):=\mathbb E_{X\sim\mathcal D}\big[p_e(X,q)\big].
]

---

## 3. Reflected load dynamics

The deterministic load dynamics are the reflected ODE
[
\dot q(t)=\Gamma(q(t)),
]
where coordinatewise
[
\Gamma_e(q)=
\begin{cases}
\lambda,\bar p_e(q)-\mu_e, & q_e>0,[4pt]
\max{\lambda,\bar p_e(q)-\mu_e,,0}, & q_e=0.
\end{cases}
]

Equivalently, in Skorokhod form,
[
q(t)=q(0)+\int_0^t F(q(s)),ds+y(t),
]
with
[
F(q):=\lambda,\bar p(q)-\mu,\qquad \mu:=(\mu_1,\dots,\mu_E),
]
where (y(t)) is coordinatewise nondecreasing, (y(0)=0), and
[
\int_0^\infty q_e(s),dy_e(s)=0,\qquad e=1,\dots,E.
]

This is the router-level analogue of the reflected dynamics in the earlier paper, but now the state is expert pressure rather than queue length.

---

## 4. Potential function

Define
[
H(q):=
\sum_{e=1}^E \mu_e^{1-\beta} q_e
+
\frac{\lambda}{\alpha},
\mathbb E_{X\sim\mathcal D}
\left[
\log!\left(
\sum_{j=1}^E
\exp!\left(
a_j(X)+\gamma\log\mu_j-\frac{\alpha(q_j+c_j)}{\mu_j^\beta}
\right)
\right)
\right].
]

### Proposition 1 (Gradient identity).

For every (q\in\mathbb R_+^E),
[
\partial_e H(q)=\mu_e^{1-\beta}-\frac{\lambda}{\mu_e^\beta}\bar p_e(q),\qquad e=1,\dots,E.
]
Equivalently, with
[
D:=\operatorname{diag}(\mu_1^\beta,\dots,\mu_E^\beta),
]
we have
[
\lambda,\bar p(q)-\mu = -D\nabla H(q).
]

**Proof.**
Differentiate the inner log-sum-exp with respect to (q_e). Since
[
\frac{\partial}{\partial q_e}
\log!\left(\sum_{j=1}^E e^{s_j(X,q)}\right)
===========================================

-\frac{\alpha}{\mu_e^\beta}p_e(X,q),
]
taking expectation gives
[
\partial_e H(q)=\mu_e^{1-\beta}
+\frac{\lambda}{\alpha},\mathbb E!\left[-\frac{\alpha}{\mu_e^\beta}p_e(X,q)\right]
==================================================================================

\mu_e^{1-\beta}-\frac{\lambda}{\mu_e^\beta}\bar p_e(q).
]
Multiplying by (\mu_e^\beta) yields
[
\mu_e^\beta\partial_e H(q)=\mu_e-\lambda \bar p_e(q),
]
which is the claimed vector identity. ∎

---

## 5. Convexity and coercivity

### Proposition 2 (Convexity).

The function (H) is convex on (\mathbb R_+^E).

**Proof.**
For each fixed (x), the map
[
q\mapsto \log!\left(\sum_{j=1}^E \exp(s_j(x,q))\right)
]
is a log-sum-exp of affine functions of (q), hence convex. The expectation of convex functions is convex, and the first term in (H) is linear. Therefore (H) is convex. ∎

### Proposition 3 (Coercivity).

If (\lambda<\Lambda:=\sum_{e=1}^E\mu_e), then (H(q)\to+\infty) as (|q|*1\to\infty) with (q\in\mathbb R*+^E).

**Proof.**
Use the elementary bound
[
\log!\left(\sum_{j=1}^E e^{u_j}\right)\ge \sum_{j=1}^E \rho_j u_j
]
for any probability vector (\rho\in\Delta_E). Choose
[
\rho_j:=\frac{\mu_j}{\Lambda}.
]
Then
[
\begin{aligned}
H(q)
&\ge
\sum_{e=1}^E \mu_e^{1-\beta}q_e
+\frac{\lambda}{\alpha},
\mathbb E!\left[
\sum_{j=1}^E \rho_j
\left(
a_j(X)+\gamma\log\mu_j-\frac{\alpha(q_j+c_j)}{\mu_j^\beta}
\right)
\right] \
&=
\sum_{e=1}^E
\left(
\mu_e^{1-\beta}-\frac{\lambda}{\Lambda}\mu_e^{1-\beta}
\right)q_e

* C \
  &=
  \left(1-\frac{\lambda}{\Lambda}\right)\sum_{e=1}^E \mu_e^{1-\beta}q_e + C,
  \end{aligned}
  ]
  where (C) is finite under the mild integrability assumption
  (\mathbb E|a_e(X)|<\infty).
  Because (\lambda<\Lambda), the coefficient of the linear term is strictly positive. Hence (H(q)\to+\infty) as (|q|_1\to\infty). ∎

## 6. Equilibrium and convergence

Let
[
\mathcal Q^\star:=\arg\min_{q\in\mathbb R_+^E} H(q).
]

Since (H) is convex and coercive, (\mathcal Q^\star) is nonempty, compact, and convex.

### Theorem 4 (Global convergence to the minimizer set).

Assume (\lambda<\Lambda) and (\mathbb E|a_e(X)|<\infty) for all (e). Then every reflected trajectory (q(t)) remains bounded, (H(q(t))) is nonincreasing, and every limit point of (q(t)) lies in (\mathcal Q^\star). Consequently,
[
\operatorname{dist}(q(t),\mathcal Q^\star)\to 0
\qquad\text{as }t\to\infty.
]
If (H) is strictly convex on (\mathbb R_+^E), then (\mathcal Q^\star={q^\star}) is a singleton and (q(t)\to q^\star).

**Proof.**
For almost every (t), we have two cases for each coordinate (e).

If (q_e(t)>0), then
[
\dot q_e(t)=\lambda\bar p_e(q(t))-\mu_e=-\mu_e^\beta,\partial_e H(q(t)),
]
so
[
\partial_e H(q(t)),\dot q_e(t)
==============================

-\mu_e^\beta\big(\partial_e H(q(t))\big)^2\le 0.
]

If (q_e(t)=0), then
[
\dot q_e(t)=\max{-\mu_e^\beta\partial_e H(q(t)),,0}.
]
Hence either (\dot q_e(t)=0), in which case the product is (0), or (\partial_e H(q(t))\le 0), in which case
[
\partial_e H(q(t)),\dot q_e(t)
==============================

-\mu_e^\beta\big(\partial_e H(q(t))\big)^2\le 0.
]
Therefore,
[
\frac{d}{dt}H(q(t))
===================

\sum_{e=1}^E \partial_e H(q(t)),\dot q_e(t)\le 0.
]

So (H(q(t))) decreases and is bounded below. By coercivity, the trajectory remains in a compact sublevel set, hence is precompact. Every limit point must satisfy the complementarity/KKT conditions for minimizing (H) over (\mathbb R_+^E). Since (H) is convex, those conditions are equivalent to membership in (\mathcal Q^\star). Thus every limit point lies in (\mathcal Q^\star), and because (\mathcal Q^\star) is compact and invariant under the flow, (\operatorname{dist}(q(t),\mathcal Q^\star)\to 0). If (H) is strictly convex, the minimizer set is a singleton, so the whole trajectory converges to that unique point. ∎

## 7. Closed form in the expert-prior special case

The general MoE case above is the right standalone formulation, but there is one important simplification that recovers a closed form.

Assume the token-affinity scores do not depend on the token:
[
a_e(X)\equiv b_e,\qquad e=1,\dots,E.
]
Then
[
w_e(q)=\mu_e^\gamma \exp!\left(b_e-\frac{\alpha(q_e+c_e)}{\mu_e^\beta}\right).
]
Define
[
\theta_e:=\mu_e^{\gamma-1}\exp!\left(b_e-\frac{\alpha c_e}{\mu_e^\beta}\right).
]

### Corollary 5 (Scalar consistency equation).

Any equilibrium (q^\star) satisfies
[
q_e^\star=\max!\left{0,\ \frac{\mu_e^\beta}{\alpha}\log!\left(\frac{\theta_e}{K^\star}\right)\right},
]
for some scalar (K^\star>0) solving
[
\lambda=\sum_{e=1}^E \min!\left{\mu_e,\ \frac{\mu_e\theta_e}{K^\star}\right}.
]

**Proof.**
At equilibrium, the reflected complementarity conditions are
[
q_e^\star\ge 0,\qquad \lambda \bar p_e(q^\star)\le \mu_e,\qquad
q_e^\star\big(\mu_e-\lambda \bar p_e(q^\star)\big)=0.
]
Let
[
W^\star:=\sum_{j=1}^E w_j(q^\star),\qquad K^\star:=\frac{W^\star}{\lambda}.
]
Then
[
\lambda p_e(q^\star)=\mu_e
\quad\Longleftrightarrow\quad
w_e(q^\star)=\mu_e K^\star.
]
If (q_e^\star>0), this gives
[
\mu_e^\gamma \exp!\left(b_e-\frac{\alpha(q_e^\star+c_e)}{\mu_e^\beta}\right)=\mu_e K^\star,
]
hence
[
q_e^\star=\frac{\mu_e^\beta}{\alpha}\log!\left(\frac{\theta_e}{K^\star}\right).
]
If (q_e^\star=0), the inequality (w_e(q^\star)\le \mu_e K^\star) gives the max-form above. Summing (w_e(q^\star)=\min{\mu_eK^\star,\mu_e^\gamma e^{b_e-\alpha c_e/\mu_e^\beta}}) over (e) and dividing by (K^\star) yields the scalar equation. ∎

This is the exact analogue of the closed-form equilibrium from the earlier paper, but now it is the equilibrium of a **load-aware MoE router**, not of a queueing CTMC.

## 8. Training-time stochastic implementation

For minibatch training, let (X_1,\dots,X_B) be the tokens in a batch and define the empirical routed mass
[
\hat r_e(q):=\frac{1}{B}\sum_{m=1}^B p_e(X_m,q)
]
for a soft router, or the corresponding hard count under top-(k) routing.

A natural reflected stochastic update is
[
q^{n+1}
=======

\Pi_{\mathbb R_+^E}!\left(
q^n+\eta_n\big(\hat r(q^n)-\mu\big)
\right),
]
with stepsizes (\eta_n>0). This is the discrete-time counterpart of the reflected flow above.

## 9. What this means for the paper

The clean mathematical claim is now:

1. the router is a reflected gradient system on (\mathbb R_+^E),
2. the router admits a convex potential (H),
3. the reflected flow is stable and convergent under subcritical load,
4. the prior-only case has a closed-form equilibrium,
5. the minibatch implementation is a stochastic approximation of that flow.

That is the right mathematical heart for a standalone MoE paper.
